# Week 31 (A2) — Grammar: Thread structure (project-style)

## Objetivo (ES)
Conectar lo aprendido y escribir un hilo completo con estructura clara:
request → update → delay → follow-up → summary.

---

## 1) Thread building blocks (A2)
- Request (Please/Can/Could/Would)
- Update (Past Simple: I sent / I checked / I received)
- Delay (Sorry for the delay + because/so + new ETA)
- Follow-up (Just following up + ETA + timeframe)
- Summary (recap + action items + owners + due dates)

---

## 2) Consistency rules
- Keep subjects consistent (same topic)
- Keep deadlines visible (by Friday / by EOD)
- Use bullets for action items

---

## Mini practice (A2)
Choose the best order:
a) Summary + action items  
b) Request  
c) Follow-up  
d) Delay  
e) Update  

Answer: b → e → d → c → a
