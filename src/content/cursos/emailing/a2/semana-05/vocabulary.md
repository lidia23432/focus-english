# Semana 05 (A2) — Vocabulary: Information, updates, documents

## 1) Uncountable nouns (A2 work)
- information
- help
- feedback
- advice
- time

## 2) Countable nouns (A2 work)
- file / files
- document / documents
- question / questions
- update / updates
- request / requests

## 3) Useful chunks (copy/paste)
- I need some information about __.
- Could you send some details, please?
- Do you have any questions?
- I don’t have any updates today.
- Please confirm.

## 4) Exercises (A2)

### A) Matching (noun → type)
Write C or U:
1) feedback → ___  
2) documents → ___  
3) information → ___  
4) questions → ___

**Answers:** 1) U  2) C  3) U  4) C

### B) Fill in (some/any)
1) Could you send ____ details, please?  
2) Do you have ____ questions?  
3) I don’t have ____ updates today.

**Answers:** 1) some  2) any  3) any

### C) Rewrite (A2)
Rewrite using some/any:
1) Please send details.  
2) Do you have questions?

Possible answers:
1) Please send some details.  
2) Do you have any questions?
