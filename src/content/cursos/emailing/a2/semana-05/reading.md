# Semana 05 (A2) — Reading: some/any in work emails

## Reading 1

**Subject:** Request for information

Hello Tom,  
I need **some information** about the project.  
Could you send **some details**, please?  
Do you have **any questions**?  
Thank you.  

Kind regards,  
Ana

### Comprehension (A2)
1) Ana needs…  
a) some information  b) an information  c) any informations  

2) Ana asks Tom to send…  
a) some details  b) some questions  c) any invoices  

3) Ana asks…  
a) Do you have any questions?  b) Do you have some questions?  c) Do you have an questions?  

4) The tone is…  
a) polite/professional  b) rude  c) angry  

**Answers:** 1) a  2) a  3) a  4) a

---

## Reading 2

**Subject:** Re: Request for information

Hi Ana,  
Sure. I attached **two files**.  
I don’t have **any updates** today.  
Would you like **some** more details?  
Please confirm.  

Best regards,  
Tom

### Comprehension (A2)
1) Tom attached…  
a) two files  b) some information  c) any file  

2) Tom doesn’t have…  
a) any updates today  b) some updates today  c) an updates  

3) Tom offers…  
a) some more details  b) any more details (incorrect here)  c) a more details  

4) Tom asks Ana to…  
a) confirm  b) pay  c) cancel  

**Answers:** 1) a  2) a  3) a  4) a

---

## Extra task (10 min)
Underline:
- some / any
- countable nouns (files, documents, questions)
- uncountable nouns (information, feedback, help)
