# Semana 17 (A2) — Writing: Online meetings (send link + troubleshoot)

## Objetivo (ES)
Escribir emails para enviar link e informar de problemas técnicos.

---

## Task 1 — Write 3 instructions (imperatives)
Write:
1) Please ___.  
2) Then, ___.  
3) Finally, ___.

(Use: click/join/check)

---

## Task 2 — Email 1: Send a meeting link (6–9 lines)
Include:
- link line
- 3 instructions (First/Then/Finally)
- polite closing

---

## Task 3 — Email 2: Report an issue (5–8 lines)
Include:
- problem (I can’t join / link doesn’t work)
- 1 polite request (Could/Would you resend…?)
- timeframe (before the meeting / today)

---

## Checklist (A2)
- Instructions are clear ✅
- I describe the issue simply ✅
- I ask politely ✅
