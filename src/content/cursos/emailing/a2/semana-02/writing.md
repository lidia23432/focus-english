# Semana 02 (A2) — Writing: Comparatives (options + recommendation)

## Objetivo (ES)
Escribir emails de decisión con comparativos para priorizar y recomendar.

---

## Task 1 — Make comparatives (10)
Write the comparative:
1) important → ___  
2) fast → ___  
3) good → ___  
4) expensive → ___  
5) early → ___  

---

## Task 2 — Rewrite (make it project-style)
Rewrite using comparatives:
1) This task is urgent. (vs another task)  
2) Option A is convenient. (vs option B)  
3) Monday is good. (vs Tuesday)

---

## Task 3 — Write an email (6–9 lines)
Situation: You have **two options** to deliver a file:
- Option A: Friday (fast)
- Option B: Monday (safer)

Write an email (internal or external — choose one) including:
- 2 comparatives (e.g., faster, safer, more urgent, better)
- 1 recommendation (I suggest / I recommend)
- 1 request using **Could you…?** to confirm the choice
- 1 deadline (by Friday / by EOD)

---

## Checklist (A2)
- I use -er / more correctly ✅
- I use better/worse correctly ✅
- My recommendation is clear ✅
- I include a deadline and a polite request ✅
