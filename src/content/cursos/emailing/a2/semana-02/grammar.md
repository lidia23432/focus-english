# Semana 02 (A2) — Grammar: Comparatives in work emails

## Objetivo (ES)
Usar comparativos para **comparar opciones** y **priorizar** en contexto de trabajo (project-style).

---

## 1) How to form comparatives (A2)

### A) Short adjectives: **-er**
- fast → **faster**
- cheap → **cheaper**
- late → **later**
- early → **earlier**

Examples:
- Option A is **faster**.
- Can we meet **earlier**?

### B) Long adjectives: **more + adjective**
- important → **more important**
- urgent → **more urgent**
- convenient → **more convenient**

Examples:
- This task is **more urgent**.
- Tuesday is **more convenient**.

### C) Irregular
- good → **better**
- bad → **worse**

---

## 2) Using “than” (simple rule)
You can use **than** when comparing two things:
- Option A is faster **than** option B.

But in emails you can also say (A2-safe):
- Option A is faster. (when context is clear)

---

## 3) Mini practice (A2)

### A) Make the comparative
1) urgent → ___  
2) good → ___  
3) cheap → ___  
4) convenient → ___

Answers:
1) more urgent  2) better  3) cheaper  4) more convenient

### B) Choose the best option
1) This is (more urgent / urgenter) than the other task.  
2) Monday is (more convenient / convenienter) for me.

Answers:
1) more urgent  2) more convenient

### C) Rewrite (project-style)
Rewrite:
1) This is urgent. → This is __.  
2) Option A is good. → Option A is __.

Possible answers:
1) This is more urgent.  
2) Option A is better.
