# Week 19 (A2) — Writing: Issue + impact + request

## Objetivo (ES)
Escribir emails pidiendo ayuda con claridad y tono profesional.

---

## Task 1 — Build the structure
Write 1 sentence for each:
1) Issue: __  
2) Impact: __  
3) Request: __

---

## Task 2 — Internal email (6–9 lines)
Situation: you can’t access a folder and the team is blocked.
Include:
- issue + impact
- 1 request with Could/Would
- timeframe (today / by EOD)

---

## Task 3 — External email (6–9 lines)
Situation: a vendor sent the wrong file.
Include:
- issue + impact
- request to resend the correct file
- polite closing

---

## Checklist (A2)
- Issue is clear ✅
- Impact is clear ✅
- Request is polite ✅
