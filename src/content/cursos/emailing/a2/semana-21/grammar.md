# Week 21 (A2) — Grammar: Attachments + versioning (v1/v2/final)

## Objetivo (ES)
Enviar adjuntos con claridad (versión correcta) y evitar confusiones en proyecto.

---

## 1) Sending attachments (A2)
- Please find attached the updated report.
- I’m attaching the latest version (v2).

## 2) Version naming (simple)
Use clear labels:
- v1 (draft)
- v2 (updated)
- final (final)

Example filenames:
- report_v2_updated.pdf
- invoice_final.pdf

## 3) Change bullets (A2)
- Changes:
  - Updated the timeline.
  - Fixed the numbers on page 2.
  - Added the VAT number.

## 4) Ask to review / confirm receipt
- Could you review the attached file by Friday?
- Please confirm receipt.

---

## Mini practice (A2)
Choose the best:
1) Please find ___ the file. (attached/attach)  
2) Could you ___ the file by Friday? (review/reviews)  
3) Please confirm ___. (receipt/receive)

Answers:
1) attached  2) review  3) receipt
