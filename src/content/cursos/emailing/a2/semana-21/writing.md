# Week 21 (A2) — Writing: Send attachment + version + changes

## Objetivo (ES)
Escribir un email enviando un adjunto con versión clara y cambios resumidos.

---

## Task 1 — Create good file names
Write 2 file names:
1) report v2  
2) invoice final

Example: report_v2_updated.pdf

---

## Task 2 — Write 3 change bullets
Write 3 “Changes:” bullets.

---

## Task 3 — Write an email (8–12 lines)
Situation: you send v2 of a document.

Include:
- Please find attached…
- version label (v2/final)
- “Changes:” + 2–3 bullets
- request to review or confirm receipt (Could you…?) + deadline (by Friday/by EOD)

---

## Checklist (A2)
- Version is clear ✅
- Changes are short ✅
- I ask politely ✅
