# Week 25 (A2) — Grammar: Problem + solution + timeframe

## Objetivo (ES)
Comunicar un problema, proponer solución y dar un plazo de forma profesional.

---

## 1) Describe the problem (A2)
- We have an issue with __.
- The file is missing / wrong / outdated.
- The link doesn’t work.

## 2) Propose a solution (A2)
- **We can** do option A.
- **I suggest** option A.
- **Another option is** option B.

## 3) Add a timeframe
- We can deliver by Friday.
- I will send an update tomorrow.

## 4) Ask to confirm (polite)
- Could you confirm which option you prefer?
- Would you confirm if Friday works?

---

## Mini practice (A2)
Choose the best:
1) I suggest option A because it is ___ (faster / fast).  
2) We can deliver ___ Friday. (by / on)  
3) Could you confirm ___ option you prefer? (which / what)

Answers:
1) faster  2) by  3) which
