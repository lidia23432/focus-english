# Week 28 (A2) — Writing: Delivery pack

## Objetivo (ES)
Escribir un email de entrega con versión clara, cambios y request de review.

---

## Task 1 — File naming (2 examples)
Write 2 filenames:
1) report v2  
2) invoice final

---

## Task 2 — Changes (3 bullets)
Write 3 change bullets.

---

## Task 3 — Write a delivery email (8–12 lines)
Include:
- attached/final line
- version label (v2/final)
- “Changes:” + 2–4 bullets
- request to review OR confirm receipt (Could/Would) + deadline (by Friday/by EOD)

---

## Checklist (A2)
- Version is clear ✅
- Changes are short ✅
- Request + deadline are clear ✅
