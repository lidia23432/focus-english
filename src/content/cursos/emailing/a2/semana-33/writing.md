# Week 33 (A2) — Writing: Portfolio 2 (6 emails)

## Objetivo (ES)
Crear tu **Portfolio A2 Set B**: 6 emails listos para reutilizar.

Write 6 emails (each 6–10 lines):

1) Internal issue + impact + request help (Could you…?)  
2) External issue + request resend + timeframe  
3) Delivery v2 + changes bullets + request review by Friday  
4) Final delivery + confirm receipt by EOD  
5) Correction: wrong date/file + correct detail + confirm  
6) Urgent but polite: blocked + deadline by EOD + thanks
