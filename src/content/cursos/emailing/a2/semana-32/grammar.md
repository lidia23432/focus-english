# Week 32 (A2) — Grammar: Portfolio set A (review focus)

## Objetivo (ES)
Consolidar estructuras A2 para crear un portfolio reutilizable.

---

## Focus checklist (A2)
- Requests ladder: Please / Can / Could / Would
- Past Simple updates: I sent / I received / I checked
- Deadlines: by Friday / by EOD
- Follow-ups: Just following up / Any update?
- Summary: action items + owners + due dates

Common errors:
- ❌ Could you to send…
- ✅ Could you send…
