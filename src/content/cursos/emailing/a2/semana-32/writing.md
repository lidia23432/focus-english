# Week 32 (A2) — Writing: Portfolio 1 (6 emails)

## Objetivo (ES)
Crear tu **Portfolio A2 Set A**: 6 emails listos para reutilizar.

Write 6 emails (each 6–10 lines). Keep them generic (work-neutral).

1) External request (Could/Would) + deadline  
2) Internal update (Past Simple + next step)  
3) External delay (apology + because/so + new ETA)  
4) External follow-up (soft + timeframe)  
5) Internal summary (3 action items with owners + due dates)  
6) External meeting proposal (2 options + mini agenda)

---

## Checklist (A2)
- Each email has a clear purpose ✅
- Tone matches internal/external ✅
- No common mistakes (Could you to…) ✅
