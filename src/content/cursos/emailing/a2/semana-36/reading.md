# Week 36 (A2) — Reading: Final portfolio outline (what you should keep)

## Objetivo (ES)
Tu portfolio final debería incluir (mínimo):

1) External request + deadline  
2) Internal update + next step  
3) External delay + new ETA  
4) External follow-up (soft + normal)  
5) Summary + action items (owners + due dates)  
6) Meeting propose + confirm + reminder  
7) Delivery v2/final + changes + request review/receipt  
8) Correction (wrong file/date) + confirmation  

Keep these as reusable templates.
