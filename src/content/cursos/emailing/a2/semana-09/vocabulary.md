# Semana 09 (A2) — Vocabulary: Documents & instructions

## 1) Document words (A2)
- invoice
- report
- contract
- updated file
- attachment
- receipt
- details

## 2) Instruction verbs (A2)
- open
- check
- review
- sign
- send back
- confirm
- reply

## 3) Useful chunks (copy/paste)
- Could you send the invoice, please?
- Please confirm receipt.
- First, please open the document.
- Then, please check the details.
- Finally, please reply by Friday.

## 4) Exercises (A2)

### A) Matching (word → meaning ES)
1) invoice → ___  
2) receipt → ___  
3) sign → ___  
4) send back → ___  

**Possible answers:** factura / recepción / firmar / devolver (reenviar)

### B) Fill in (First/Then/Finally)
1) ____, please open the document.  
2) ____, check the details.  
3) ____, confirm receipt.

**Answers:** First / Then / Finally

### C) Build 6 instruction lines
Write 6 short instruction lines using:
First / Then / Finally / check / confirm / reply
