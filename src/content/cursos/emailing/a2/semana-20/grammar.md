# Week 20 (A2) — Grammar: Giving clarification (steps + examples)

## Objetivo (ES)
Aclarar información de forma simple: pasos + un ejemplo (project-style).

---

## 1) Clarification starters (A2)
- Here is the information:
- To clarify:
- Just to clarify:

## 2) Steps (review)
- First, …
- Then, …
- Finally, …

## 3) Add an example (A2)
- **For example,** you can use the PDF version.
- **For example,** the deadline is Friday by EOD.

✅ Tip: un ejemplo ayuda a evitar malentendidos.

---

## Mini practice (A2)

### A) Choose the correct connector
1) ___, open the file. (First/Finally)  
2) ___, check page 2. (Then/First)  
3) For ___, use the PDF. (example/examples)

Answers:
1) First  2) Then  3) example

### B) Rewrite (add an example)
Rewrite:
1) Please use the correct version.

Possible answer:
- Please use the correct version. For example, use v2 (not v1).
