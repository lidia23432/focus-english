# Week 24 (A2) — Reading: Same message, two tones

## Objetivo (ES)
Comparar un email interno y otro externo con el mismo objetivo.

---

## Reading 1 — Internal

**Subject:** Quick request — updated file

Hi team,  
Please send the updated file today.  
Can you confirm the deadline by EOD?

Thanks,  
Alex

Questions:
1) Which request forms are used?  
2) Is the tone internal or external?

## Reading 2 — External

**Subject:** Request — updated file (deadline)

Hello Jordan,  
Could you please send the updated file today?  
When possible, would you confirm the deadline by EOD?

Thank you in advance,  
Alex

Questions:
1) Find two softeners/polite choices.  
2) Why is this tone suitable for an external email?
