# Semana 05 — Grammar (A1): There is / There are + simple instructions

## Objetivo (ES)
Compartir links/archivos usando There is/There are + pedir confirmación.

## There is / There are
- There is a link.
- There are two files.

## Please + verb
- Please check the link.
- Please open the file.
- Please confirm.

Mini:
1) There __ a link. (is/are) → is
2) There __ two files. (is/are) → are
