# Emailing A1 — Semana 07 — Grammar
**Tema:** Imperatives + Please (A1) + “attached”  
**Duración:** 10–15 min

## Micro‑lección
Frases útiles para adjuntos:
- **Please find attached** the file.
- **Here is** the file.
- **This is** the new version.

Imperatives (A1) con cortesía:
- **Please check** the file.
- **Please confirm**.

## Ejercicios

### A) Completa (use: find / check / confirm)
1) Please ___ attached the file.  
2) Please ___ the file.  
3) Please ___ the time.

### B) Elige la mejor opción (A o B)
4) A) Find attached the file.  B) Please find attached the file.  
5) A) Please check the file.  B) Check the file now!!!

### C) Ordena las palabras
6) attached / please / find / the file  
7) new / is / this / version / the

## Soluciones
1) find  
2) check  
3) confirm  
4) B  
5) A  
6) Please find attached the file.  
7) This is the new version.
