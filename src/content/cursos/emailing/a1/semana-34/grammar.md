# Semana 34 — Grammar (A1): Template kit (review)

## Objetivo (ES)
No hay “gramática nueva”: esta semana es para **automatizar** patrones A1 correctos.

---

## 1) 4 patrones A1 para emails de trabajo
1) **Please + verb**
- Please confirm.
- Please send the file.

2) **Can you…?, please?**
- Can you resend it, please?

3) **This is to confirm…**
- This is to confirm our meeting on Tuesday at 10:00.

4) **There is / There are**
- There is a link: __
- There are two files attached.
