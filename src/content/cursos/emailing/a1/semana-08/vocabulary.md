# Semana 08 — Vocabulary (A1): Attachments

## 1) Core words (16)
attached, attachment, file, document, PDF, invoice, form, contract, review, sign, send back, receipt, confirm, check, details, signature

## 2) Useful chunks
- Please find attached __.
- I attach __.
- Please review __.
- Please sign __.
- Please confirm receipt.

## 3) Exercises
A) Matching (invoice/form/contract → ES)
B) Gap-fill: attached / review / sign / confirm (12 items)
C) Build 6 short sentences using the chunks.
