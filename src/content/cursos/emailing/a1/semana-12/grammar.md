# Emailing A1 — Semana 12 — Grammar (Consolidación 3)
**Tema:** Repaso: Do you…? + because + please + short answers  
**Duración:** 20–25 min

## Micro‑recordatorio
- **Do you have…?** (pregunta)
- **Yes, I do. / No, I don’t.** (respuesta corta)
- **Please send it** (petición)
- **because** (razón)

---

## Ejercicios (24)

### A) Completa (Do / do / don’t)
1) ___ you have the price list?  
2) Yes, I ___.  
3) No, I ___.

### B) Elige la opción correcta
4) Do you (have / has) the schedule?  
5) Yes, I (do / am).  
6) No, I (don’t / not).

### C) Une con because
7) I need it today. Please send it.  
8) I am busy. I can’t meet.

### D) Ordena las palabras
9) follow-up / a / is / this  
10) reminder / a / just / is / this  
11) because / need / I / it / today  
12) you / do / have / the file

### E) Completa la frase
13) This is a ________. (follow-up)  
14) Just a ________. (reminder)

### F) Convierte a pregunta (Do you…?)
15) You have the file. → ____________?  
16) You have the schedule. → ____________?

### G) Escribe 4 frases útiles (A1)
17) __________________________________  
18) __________________________________  
19) __________________________________  
20) __________________________________  
(usa: This is a follow-up / Just a reminder / Please send it / Please confirm)

### H) Corrige el error
21) Do you has the price list?  
22) Yes, I am.  
23) Please send it because I need today.  
24) This is follow up.
